# cocoBar v0.7.1

- Fixed corner placement: the wider carrying pose no longer keeps the standing cat away from the screen edges.
- Fixed deleted letters remaining visible in Notes, including overlapping text after Backspace, Delete, or replacing a selection.
- Fixed the cat jumping between displays while dragging. Dropping keeps the display selected by the pointer.
- Fixed saved positions and resizing on displays to the left or above the main screen.
- Improved position recovery when a display is disconnected or rearranged.

Download **cocobar.exe** from the release assets and run it directly. Windows 64-bit; no installer needed. Your existing notes, tasks, and settings are preserved in `%APPDATA%\cocoBar`.
